# Listing assets

Web-sized photos for Eric Coulombe's custom listing pages on ericcoulombe.com.
Each listing gets its own folder; the pages themselves live on myRealPage and load
these photos from https://stats.ericcoulombe.com/listings/<listing>/img/.
Fonts come from /assets/fonts (shared E&V brand fonts).

Don't rename or delete a listing's folder while its page is live (including the Sold stage).
